Portreaper

收割端口上的僵尸进程。

找出谁在占用端口，看清是谁拉起的，然后一键终结那些父进程已死、却还赖在端口上的孤儿 dev-server。

应用界面

不是又一个端口查看器

核心价值是僵尸识别和启动链 —— 帮你分清「正在干活的进程」和「该被收割的孤魂」。

僵尸识别

置信度分层（confirmed / likely / possible）综合孤儿、孤儿链、会话失效等信号判定。launchd / Homebrew 后台服务自动豁免 —— 不误报正在服务的进程。

启动链

沿父进程链一路上溯，看清这个进程到底是谁拉起的：Terminal → zsh → npm → vite。一眼分辨「我自己开的」还是「不知哪来的孤儿」。

一键清扫

批量终止所有 Confirmed + Likely 的僵尸进程，一次释放占用的端口。白名单收藏的进程永远豁免，绝不被误杀。

跨平台

常驻 macOS 菜单栏与 Windows 系统托盘，关窗即隐藏、不打断工作流。界面中英双语，托盘标题实时显示可疑进程数。

安装与首次启动

应用未经签名公证。下面是绕过系统拦截的标准步骤。

  1. 打开下载的 .dmg，把 Portreaper 拖入「应用程序」后再打开 —— 不要直接在 dmg 里双击运行（会触发 App Translocation，下面的步骤会失效）。
  2. 首次打开若提示「无法验证开发者」：前往「系统设置 → 隐私与安全性」，点最下方的「仍要打开」。
  3. 或者在「应用程序」里 右键 → 打开，在弹窗里再次确认「打开」。
  4. 若提示的是「已损坏，无法打开」（未签名 App 的常见报错，此时「仍要打开」常常不出现、右键打开也无效）：右键 dmg 里随附的「解除隔离 Remove Quarantine.command」→「打开」，自动移除隔离并启动（v0.7.1 起附带；脚本自身也带隔离标记，需右键而非双击）。或在终端手动执行：
xattr -dr com.apple.quarantine /Applications/Portreaper.app
  1. 运行 .exe 安装包。若出现 SmartScreen 蓝屏，点击「更多信息 → 仍要运行」。
  2. 杀毒软件可能误报 —— 本应用需要枚举并终止进程，这类行为容易被启发式引擎标记。可将其加入信任列表。
实验性 Windows 版本目前仅经过 CI 编译与单元测试，尚未在多机型上充分验证。欢迎在 issue 区反馈问题。
